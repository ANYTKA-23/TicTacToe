# Руководство пользователя
Цель игры «Крестики‑нолики» — первым выстроить три своих знака (крестика или нолика) в ряд на поле 3×3.

Основные правила:
1. Ходы делаются по очереди. Первый ход делают крестики.

![a](https://github.com/ANYTKA-23/TicTacToe/blob/main/нач.png)

2. Победа наступает, когда игрок выстраивает три своих символа в ряд:
- по горизонтали (любая из трёх строк),

![q](https://github.com/ANYTKA-23/TicTacToe/blob/main/гориз.png)

- по вертикали (любой из трёх столбцов),

![qщ](https://github.com/ANYTKA-23/TicTacToe/blob/main/вертик.png)

- по диагонали (любая из двух диагоналей).

![qн](https://github.com/ANYTKA-23/TicTacToe/blob/main/дагон.png)

3. Есть ещё ничья
- когда ни один игрок не выставил три своих символа в ряд

![b](https://github.com/ANYTKA-23/TicTacToe/blob/main/ничья.png)

4. Для повтора игры можно нажать "заново"

![bва](https://github.com/ANYTKA-23/TicTacToe/blob/main/занов.png)
